# **Design System Specification**

Project: Africa Solid Waste Observatory UI Kit  
Theme: Sustainable Data Clarity Theme

## **1\. Color Palette**

* **Primary:** Primary Green  
* **Secondary:** Secondary Blue  
* **Accent:** Accent Yellow  
* **Text/Neutral:** Text Dark  
* **Background:** Background Light

## **2\. Typography**

**Font Family:** Inter

| Role | Weight | Description |
| :---- | :---- | :---- |
| **H1** (Main Headline) | Extrabold | Primary page titles |
| **H2** (Section Title) | Bold | Major section dividers |
| **H3** (Sub-Section) | Semibold | Subsection headers |
| **H4** (Card Title) | Medium | Card and feature titles |
| **Body** | Normal | Standard text for reports and summaries; legible and clear |
| **Caption/Footer** | Normal/Light | Helper text and footers |
